# COMP3250_Project

Data:
https://www.kaggle.com/c/fake-news/data
https://onlineacademiccommunity.uvic.ca/isot/2022/11/27/fake-news-detection-datasets/

The raw `Combined_Corpus_Dataset/Data/Train` and `Combined_Corpus_Dataset/Data/Test`
shards are kept in-repo. The generated cleaned outputs
`combined_corpus_cleaned.csv` and `combined_corpus_cleaned.parquet` are not
versioned because they are reproducible from the raw shards and exceed
GitHub's file size limits.
